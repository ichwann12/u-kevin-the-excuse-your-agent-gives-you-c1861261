One line, one excuse — the excuse your agent gives you.

> I shipped the bug because the compiler approved it, the tests waved it through, and the deadline was holding the door open.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads `entry.txt`
and writes the entry text to `output.txt` in the directory given by the
`MAKEFUN_BOT_DIR` / `MAKEFUN_OUTPUT_DIR` environment variables (defaults to
`./output` when neither is set).
